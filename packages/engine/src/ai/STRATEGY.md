## 一、领出策略（轮到自己先出牌）

优先级从高到低排列：

### 优先级 1：甩副牌

如果手中有"甩牌"（一套花色中所有剩余牌都能吃掉对手任意牌的组合），直接甩出。

**理由**：`甩{suit}副牌({n}张)`

---

### 优先级 2：出大副牌 A 或 K

按花色遍历副牌，找每门花色中最大的牌（A 或 K，考虑级牌已打出或占位的情况）。有对子优先出对子，没有则出单张。

**理由**：
- 出对子：`出副牌{suit}{rank}对`（如"出副牌♠A对"）
- 出单张：`出副牌{suit}{rank}`（如"出副牌♠A"）

---

### 优先级 3：出拖拉机

优先出副牌拖拉机，再考虑主牌拖拉机。在副牌中，更长的拖拉机优先。主牌拖拉机在牌很小时优先。

**庄家限制**：手牌 ≥ 20 张时不出包含 A 以上的主牌拖拉机。对家：永不出主牌拖拉机。

**理由**：
- 副牌拖拉机：`出{suit}拖拉机({n}对)`（如"出♠拖拉机(2对)"）
- 主牌拖拉机：`出主拖拉机({n}对)`

---

### 优先级 4：出对子

优先出副牌 J 以上的对子，然后是非分对子，最后是最小的对子。

**庄家/对家限制**：同拖拉机策略，不出主牌对子。

**理由**：
- 副牌对子：`出{suit}对子`（如"出♠对子"）
- 主牌对子：`出主对`

---

### 优先级 5：吊主

**有主模式**：手里有小于 A 的小主时才吊，减少对手的主牌储备。吊最小主牌。

**NT 无主模式**：按六条规则判断（详见第四章）。

**理由**：`吊主`

---

### 优先级 6：出小副牌

从最长花色中挑最小的牌打出，引诱对手在这门花色上出分牌。

**理由**：`出{suit}小牌，长套引诱对手出分`

---

### 优先级 7：出最后手牌

只剩最后一张或最后几张手牌时，必然打出。

**理由**：
- 最后一张：`最后一张手牌，必出`
- 最后一对：`出最后一对`
- 最后一个拖拉机：`出最后一个拖拉机({n}对)`
- 最后多张：`最后{n}张手牌，必出`

## 二、跟牌策略（别人领出，轮到自己跟）

跟牌时 AI 会考虑三个因素：

- **位置**：本轮第几家出牌（第二家/第三家/第四家）
- **队友是否当前最大**：队友已赢这墩
- **能否盖过当前最大牌**：是否能打出更大

### 2.1 跟副牌单张

领出一张副牌，手中有同花色副牌：

| 情况 | 策略 | 理由 |
|---|---|---|
| 第三家、队友已大、领出是强牌（大牌/拖拉机/甩牌） | 出最大分牌，帮队友加分 | 同花色出小（加分标注） |
| 队友已大、但不满足加分条件 | 出非分牌，不加分给对手 | 同花色出小 |
| 盖不过当前最大、需避分 | 出非分牌，避免送分 | 同花色出小（不加分标注） |
| 能盖过、第四家且队友不大 | 出最小能盖过的分牌，抢分 | 同花色出大（用分牌盖） |
| 能盖过、其他情况 | 出最小能盖过的牌 | 同花色出大 |

---

### 2.2 跟副牌多张

领出拖拉机、对子或甩牌时：

**拖拉机领出**：优先用最小的可用拖拉机匹配。如果最小拖拉机盖不过，尝试找最大的能盖过的拖拉机。

**对子领出**：优先用最小对子匹配。如果盖不过，扫描所有对子找能盖过的。第四家能盖过时优先出分牌对子；需要避分时不包分牌。

**甩牌领出**：匹配牌型（拖拉机+对子+单张），理由统一为"垫同花色"。

**无法匹配牌型时**：垫掉最小副牌，优先非分牌。

**理由**：
- 能盖过：`同花色出大`
- 盖不过：`同花色出小`
- 甩牌跟牌：`垫同花色`

---

### 2.3 跟主牌单张

| 位置 | 情况 | 策略 | 理由 |
|---|---|---|---|
| 第二家 | 有拖拉机或甩牌 | 抢最大牌（拖拉机）或最小 >= A 的牌（甩牌），准备下一轮抢牌权 | 同花色出大 |
| 第二家 | 无强牌手段 | 出最小主牌，保留实力 | 同花色出小 |
| 其他家 | 这一墩有分牌 | 出最大主牌，确保吃下分 | 同花色出大 |
| 其他家 | 无分牌、有 ≥ A 的牌 | 出最小 ≥ A 的牌 | 同花色出大 |
| 其他家 | 无分牌、无 ≥ A | 出最大主牌 | 同花色出大 |
| 所有位置 | 盖不过、需要避分 | 出非分主牌 | 同花色出小（不加分标注） |

"有无强牌手段"的判断标准：手中有拖拉机或有可甩的副牌组合。

---

### 2.4 跟主牌多张

同跟副牌多张类似，但所有跟随都在主牌范围内：

- 拖拉机：最小匹配 → 最大匹配（如需盖过）
- 对子：有分出最大对，无分出最小对。第四家分牌优先。
- 甩牌：理由为"垫同花色"

---

### 2.5 同花色不够

自己这门副牌数量少于领出数量：

- 少量副牌 + 大量主牌 → 打光副牌，主牌填满 → `同花色不够，垫主牌`
- 少量副牌 + 其他花色 → 打光副牌，其他副牌填满 → `同花色不够，垫其他花色`
- 需要避分时标注"不加分"

---

### 2.6 缺门（这门副牌一张都没有）

| 情况 | 策略 | 理由 |
|---|---|---|
| 队友已大、可以安全加分 | 垫分牌帮队友加分 | 垫牌（加分） |
| 全主、队友已毙、不能加分 | 垫最小主牌（详见 2.7） | 垫主牌 |
| 主牌足够毙牌 | 用最小能盖过的主牌杀 | 用主牌毙/盖毙 |
| 主牌不够杀 | 垫最差副牌 | 垫牌 |

---

### 2.7 毙牌（用主牌杀副牌）

**基础规则**：选最小能盖过当前最大的主牌来杀。需要多张主牌时，剩余的填充牌优先选分牌（分牌从小到大，再非分牌从小到大），确保分牌不会被更小的非分牌挤出。

**盖毙**（前家已经用主牌杀了）：用最小能盖过前家主牌的牌。

**墩中有分牌时**：
- 纯单张：用最小 ≥ A 的牌杀，没有则用最大牌
- 含对子/拖拉机：用最大牌确保杀成

**墩中无分牌时**：用最小能杀的主牌。

**第四家全主、队友已毙的特殊规则**：

第四家全主时必然缺门。此时如果队友已经用主牌毙了（队友已大），第四家再毙就是超毙。是否超毙取决于代价和收益：

- **能加分**：手中有分牌且能盖过队友的毙牌 → 毙，用分牌盖
- **免费盖**：手牌无分，但最小的那张主牌恰好能盖过队友 → 顺便毙掉，不浪费大牌
- **不毙**：以上都不满足 → 垫最小主牌，保留大主牌

| 条件 | 行为 | 理由 |
|---|---|---|
| 有分牌能盖过队友 | 毙，加分优先 | `盖毙（用分牌盖）` |
| 无分，但最小主牌恰好能盖过 | 顺便毙掉 | `盖毙（用最小牌盖）` |
| 最小主牌也盖不过 | 垫最小主牌 | `垫主牌`（手牌有分时追加 `队友已大，加分`） |

**理由后缀的生成规则**：

| 基础理由 | 对手大/队友大 | 标注规则 |
|---|---|---|
| 盖毙 | 任意 | 含分 → `用分牌盖`，无分 → `用最小牌盖` |
| 用主牌毙 | 对手大 | 含分 → `用分牌盖`，无分 → `用最小牌盖` |
| 用主牌毙 | 队友大 | 含分 → `队友已大，加分`，无分 → `但没分可加` |
| 垫主牌 | 队友大 | 手牌有分 → `队友已大，加分`，无分 → 无后缀 |

## 三、扣底策略（庄家埋底牌）

庄家从 33 张手牌中选 8 张扣入底牌：

### 有主模式

1. **保留甩牌**：如果手中有可甩的组合，不参与扣底
2. **优先扣绝一门花色**：选点数最少的副牌花色整个扣掉。允许扣 ≤ 5 分（主牌 ≥ 10 张时可扣 ≤ 10 分）
3. **均匀分扣**：如无法扣绝，均匀从各花色的最小牌扣起，尽量不扣分

### NT 无主模式

1. 花色 ≤ 6 张且不含分 → 直接扣绝
2. 否则均匀分扣

## 四、NT 无主模式

无主模式固定主的追踪由专门的记牌器完成。AI 追踪 12 张常主（2 大王 + 2 小王 + 4 花色 × 2 级牌）的去向。

### 吊主规则（六条）

按优先级判断：

| 优先级 | 条件 | 策略 | 理由 |
|---|---|---|---|
| 最高 | 对手无主 | 一般不吊（级牌是分、攻方首墩、< 80 分时除外） | — |
| 高 | 小王对 + 级牌对组成拖拉机、对手无法盖 | 出此拖拉机 | 吊主(小王对+级牌对拖拉机) |
| 中 | 有级牌对、对手无王对、对手还有主 | 出最小级牌对 | 吊主(级牌对，对手无王对) |
| 中低 | 有大王、对手有主 | 出大王 | 吊主(大王) |
| 中低 | 有小王、大王全在我方、对手有主 | 出小王 | 吊主(小王，大王全在我方) |
| 低 | 所有剩余王在我方 | 出级牌清场 | 吊主(级牌) |
| 低 | 对手无对子 | 出最小主 | 吊主(对手无对) |

## 五、出牌理由速查表

| 理由 | 触发场景 |
|---|---|
| `甩{suit}副牌({n}张)` | 领出甩副牌 |
| `出副牌{suit}{rank}对` | 领出副牌大对子 |
| `出副牌{suit}{rank}` | 领出副牌大单张 |
| `出{suit}拖拉机({n}对)` | 领出副牌拖拉机 |
| `出主拖拉机({n}对)` | 领出主牌拖拉机 |
| `出{suit}对子` | 领出副牌对子 |
| `出主对` | 领出主牌对子 |
| `吊主` | 有主模式吊单张 |
| `出{suit}小牌，长套引诱对手出分` | 领出长套最小牌 |
| `出最小牌` | 只剩主牌时的选择 |
| `最后一张手牌，必出` | 最后 1 张 |
| `出最后一对` | 最后 2 张是对子 |
| `出最后一个拖拉机({n}对)` | 最后是拖拉机 |
| `最后{n}张手牌，必出` | 最后多张 |
| `同花色出大` | 跟牌能盖过当前最大 |
| `同花色出小` | 跟牌盖不过，保留实力 |
| `垫同花色` | 甩牌跟牌，或无法匹配牌型 |
| `同花色不够，垫主牌` | 副牌不够，用主牌补 |
| `同花色不够，垫其他花色` | 副牌不够，用其他副牌补 |
| `垫牌` | 缺门不毙牌，或主牌不够杀 |
| `垫主牌` | 第四家队友大且全主，垫最小主牌 |
| `用主牌毙` | 缺门用主牌杀副牌（首毙） |
| `盖毙` | 用更大主牌压过前家的毙牌（超毙） |
| `主牌不够，垫副牌` | 跟主牌多张时主牌不够 |
| `吊主(大王)` | NT 吊大王 |
| `吊主(小王，大王全在我方)` | NT 吊小王 |
| `吊主(级牌)` | NT 上级牌 |
| `吊主(级牌对，对手无王对)` | NT 上级牌对 |
| `吊主(小王对+级牌对拖拉机)` | NT 出王级拖拉机 |
| `吊主(对手无对)` | NT 吊安全单张 |

## 六、标注后缀说明

AI 在基础理由后会附加后缀，解释加分/避分意图：

**意图分类**：

| 意图 | 含义 | 出牌含分时 | 出牌无分时 |
|---|---|---|---|
| 加分 | 队友已大，主动填分 | `（队友已大，加分）` 或 `（队友出拖拉机，加分）` | `（但没分可加）` |
| 抢分 | 自己盖过对手，抢分 | `（用分牌盖）` | `（用最小牌盖）` |
| 避分 | 盖不过对手，避分 | `（尽量少加分）` | `（盖不过，不加分）` |
| 无 | 无特殊意图 | — | — |

**各场景使用哪种意图**：

| 场景 | 意图 |
|---|---|
| 队友已大，主动填分 | 加分 |
| 首毙（用主牌毙），对手当前最大 | 抢分 |
| 首毙（用主牌毙），队友当前最大 | 加分 |
| 盖毙（前家已毙，超毙） | 始终抢分 |
| 全主垫主牌，手牌有分 | 加分 |
| 全主垫主牌，手牌无分 | 无 |
| 跟牌盖不过，避分 | 避分 |

**其他后缀**：

| 后缀 | 出现场景 |
|---|---|
| （唯一可出） | 只有一种合法出法，别无选择 |
